# Julia bindings

The [`LlingLlang`](LlingLlang/README.md) package gives Julia applications
idiomatic access to lling-llang's weighted finite-state transducer (WFST)
builder, snapshot resources, lazy composition, and host-provider interface.
The package is versioned `4.0.0-rc.5`; it is a build-only release candidate
and is not published by this feature branch.
